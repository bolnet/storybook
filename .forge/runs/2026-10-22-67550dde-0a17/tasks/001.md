# Task 001

Move the serialized-param merge into `code/core/src/manager-api/lib/url.ts` as an exported `mergeSerializedParams` that keeps a pair whose value is an empty string and still discards a pair whose key is empty, and have `getStoryHrefs` call it.

Serves: Spec "Decisions and evidence": the `key && value` filter in `parseSerializedParam` (`modules/url.ts:49`) throws away empty-string args, which is AC-01 to AC-04; AC-05 guards that empty keys stay discarded and nothing empty is invented.

Produces:
- mergeSerializedParams(params: string, extraParams: string): string, exported from code/core/src/manager-api/lib/url.ts

May touch: code/core/src/manager-api/lib/url.ts, code/core/src/manager-api/modules/url.ts
Tests under: code/e2e-internal

Definition of done: `code/core/src/manager-api/lib/url.ts` exports `mergeSerializedParams(params: string, extraParams: string): string` beside the existing `buildNavigationUrl`. It splits each `;`-separated pair of both arguments on `:`, URI-encodes the value as the current code does, discards a pair only when its key is empty, lets a key present in `extraParams` override the same key from `params`, and joins the result back with `;`. So `'label:'` round-trips to `'label:'`, `'text:;radio:'` keeps both pairs, `''`, `';'` and `':x'` each yield no pair and therefore no bare `:` in any built link, `'equal:g=h'` still yields `'equal:g%3Dh'`, and `'abc'` still yields `'abc:undefined'`. `parseSerializedParam` is private to that module.

`code/core/src/manager-api/modules/url.ts` no longer defines either helper: it extends its existing `import { buildNavigationUrl } from '../lib/url.ts'` to bring in `mergeSerializedParams`, and `getStoryHrefs` calls it exactly as before for both `args` and `globals`, with the rest of the function unchanged.

The unit spec is a new file under the task's test root (`code/e2e-internal/unit/serialized-params.spec.ts`) and reaches the helper at call time rather than through a static import, so that at the `tests:` commit — where the export does not exist yet — every one of its tests fails on an `expect`, not on a module error: `const mod = await import('../../core/src/manager-api/lib/url.ts').catch(() => ({}))`, then `const mergeSerializedParams = (mod as any).mergeSerializedParams ?? (() => undefined)`, and each test asserts on what that call returns.

Green state: every test collected by `code/e2e-internal/unit/serialized-params.spec.ts` passes, and all five tests of `code/e2e-internal/isolation-mode-empty-args.spec.ts` pass. AC-05 in that file is the invariant guard — it passes before this task and must still pass after, with the opened tab carrying no `args` parameter and no pair starting with `:` anywhere in its query.
